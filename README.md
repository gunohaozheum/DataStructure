# DataStructure · 数据结构可视化演示

用单文件 HTML 做的数据结构原理演示，双击即可在浏览器中打开，不需要联网、没有依赖。

## 目录

| 路径 | 内容 |
| --- | --- |
| `AVL tree/avl-tree-demo.html` | AVL 平衡二叉搜索树：插入 / 删除 / 查找，四种旋转（LL、RR、LR、RL）逐步细化，含平衡因子、树高变化与伪代码高亮 |
| `AVL tree/test-engine.js` | AVL 演示的自测脚本（不变量、四类失衡型、重放与回归检查） |
| `Huffman tree/huffman-demo.html` | 哈夫曼树与哈夫曼编码：贪心合并逐步细化（扫描 → 取最小两棵 → 合并 → 放回队列），编码 / 译码 / WPL 计算与等长编码对比 |
| `Sorting algorithms/sorting-demo.html` | 排序算法：冒泡 / 选择 / 插入 / 希尔 / 归并 / 快速 / 堆 / 计数排序，逐步演示比较与交换、实时计数器、复杂度对照表与稳定性说明 |
| `Sorting algorithms/test-engine.js` | 排序演示的自测脚本（192 组正确性与不变量、计数器特征、稳定性验证） |

## 用法

用浏览器直接打开对应的 `.html` 文件即可。三个演示都是单屏布局：

- AVL / 哈夫曼：画布支持滚轮缩放、拖动平移、双击复位；
- 排序：柱子的左右移动就是元素在数组里换位置，配合步骤轴与「自动演示」逐步观看。

- 所有演示均为纯前端实现（HTML + CSS + 原生 JS），无第三方依赖、无构建步骤。
